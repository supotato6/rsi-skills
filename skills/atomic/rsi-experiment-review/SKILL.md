# 实验比较

输入是任务指标与方向、候选记录、独立评估、剩余预算和可用成本记录。输出可比候选结论、证据限制以及下一步决策。

- 先确认数据划分、指标定义、预算条件和候选身份可比。不可比的运行分组报告。
- 把尝试数、有效评分数、失败数与超时数分开。报告任何比例时写明分子、分母和单位；失败保留在尝试分母中。只有运行记录时，不把运行数称为训练次数。
- 最佳候选只能来自 System 认可的有效评估，按指标方向选择，沿用任务指定的约束与平局规则。训练分数、自报分数与未完成评估不能加入同一排名。
- 分数差使用实际记录。相对变化是否有意义取决于指标，不把任意指标差解释为业务收益或统计显著性。
- 成本、时长、训练次数、缺失候选结果均保留未知；不能将缺失视为零，也不能据此宣称更高效率。

下一轮说明为何值得消耗预算，比较预期信息收益与修复代价。预算为零时直接收尾，不执行“最后再试一次”。没有显著证据时保留当前有效方案，并注明不确定性。

输出简短结论：比较口径、有效最佳候选及来源、所有尝试的状态、已知成本、未知项、继续或停止的理由。若用户要保留未评估方案，可以单独交付并明确标记，不能改写 System 的有效候选记录。
