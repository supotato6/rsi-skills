# 复现证据与失败合同

证据等级与执行方式分开。System 从实际回执校验身份；模型声明只作为待审核材料。

| 证据 | 内容 | 不能推出 |
| --- | --- | --- |
| source_verified | 固定 Notebook 版本、源码及 metadata 哈希 | 已运行或分数匹配 |
| local_source_execution | 输入清单/哈希、实际镜像 ID、全量源码执行命令、退出状态、日志和输出哈希 | 本地完成隐藏评测 |
| public_output_reuse | 公开输出的来源版本、原始哈希、实际复用范围 | 原源码重跑或重新训练 |
| smoke_only | 执行子集、跳过/占位范围、诊断结果 | 全量运行或可正式提交 |
| score_matched | 正式 submission_id、候选身份、控制器真实查分、目标成绩与精度/容差；可信指标方向下优于目标也达标 | 超过当前所有开源方案 |

预测文件提交要绑定本地实际输出和冻结提交字节；代码提交还要绑定实际私有上传版本、源码、输入声明及 Kaggle 执行。仅执行打包 Notebook 时，执行种类为 packaging；不能说已经在本机重跑 Agent 的所有隐藏任务。

原版基线模式保留同字节源码，只允许为私有提交调整资源身份/可见性。必要的路径或依赖适配保存为独立变体，不能覆盖原版或把变体成绩写到原版名下。未找到不可变依赖版本时明确 gap；即使当前数据能运行，也不宣称依赖完全等同。

失败记录包含 competition、run_id、来源版本和哈希、失败阶段、错误类别、证据路径、尝试的修复、结论及下次建议。推荐类别：

- environment：镜像不可取得、包/ABI/CUDA 不兼容、设备不可用。
- inputs：缺文件、私有资源、依赖版本不明、路径或挂载不匹配。
- execution：原源码异常、超时、显存/内存问题、服务接口不兼容。
- artifact：输出缺失、行数/ID/格式不符、打包不完整。
- submission：提交方式错误、远端拒绝、接受状态不确定。
- score：正式评分未完成、目标不符、指标/榜单/阶段不可比。

失败记录存任务工作区和控制器经验索引，完整日志保留本地，索引只存必要信息与路径。保留失败不等于允许无限重试；重试须有新证据或明确修复，正式提交次数仍由 System 约束。

阶段交接时冻结实际官方基线的 submission_id、成绩、指标方向和来源身份。优化后只比较另一条已完成正式提交在同比赛、同 Public 榜单的实际成绩；高分更好时收益为 after − before，低分更好时为 before − after。零分有效，基线为零时不计算相对收益。pending、查分失败或模型报告的本地分数不能产生官方收益；收益为负时如实保留回退依据。后续刷新基线不能改写已开始优化任务的原始对照成绩。

already_met 允许跳过复现与新提交，但已有成绩与当前公开源码之间缺少生成关系时，不构成优化来源证据。optimize 交接必须引用产生该官方提交的 verified 原运行；禁止将另一个开源方案的源码与已有成绩拼接后称为已验证基线。
