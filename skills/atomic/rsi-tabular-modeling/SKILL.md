# 表格建模

输入是公开训练数据、已确定的验证约定、指标、资源预算与产物契约。输出可重放的候选程序或模型、配置与预测产物。

- 先检查字段类型、缺失、常量、实体 ID、类别比例及预测时不可获得的字段。保留输入 ID 和行对应关系，目标列与泄漏字段不进入特征。
- 在现有环境内建立低成本可运行基线。模型复杂度与数据规模、指标和资源相匹配；不为了遵循示例引入新依赖或大规模搜索。
- 数据处理与模型一起保存。训练内拟合的统计量不能来自验证集或测试集；固定种子、特征顺序、类别映射和推理入口。
- 每轮提出一个可判断的改动假设，说明预期收益和资源代价，再执行候选。需要同时调整多个因素时承认无法从该轮单独归因。
- 保留候选身份、父版本、数据与验证版本、程序或模型路径。训练分数只作诊断，未评估候选的独立分数记为未知。

调用已有的 System 执行或评估工具确认候选有效性。没有该工具时可以交付候选与本地检查，但明确其评分未经 System 验证。

候选应在约定资源内完成并产生契约要求的文件。失败时保留失败阶段和日志；预算耗尽时不启动新的实验。最终使用 System 选定的有效候选，未经重新验证的改动另标为未评估版本。
