# 产物检查

输入是任务产物契约、预期输入标识与候选产物。输出逐项检查结果、可交付路径与尚未验证的事项。

1. 读取实际契约，检查文件存在、可解析、格式、必需字段、类型与行数。不能凭常见竞赛格式猜测当前契约。
2. 按契约核对 ID 集合、重复与缺失、额外记录和输出顺序。需要对齐时根据真实预测与输入的对应关系修复，不能填造缺失预测。
3. 数值检查 NaN、无穷大，以及任务规定的概率或其他边界。概率多列是否需和为一由任务语义决定。异常先追溯生成链路，不把无依据裁剪当成模型正确性的证明。
4. 检查模型、预处理、特征顺序与推理代码是否属于同一候选。文件变动后旧评分不能自动代表新版本；记录最终文件哈希或复用 System 的候选快照。
5. 在消耗独立评估预算前完成可执行的本地格式检查。本地检查通过只证明相应契约项，不等于真实评估通过或分数提高。

有阻断问题时返回明确原因和修复所需信息。最终交付标明检查通过项、未运行项、绑定候选及可信评估来源。外部上传遵循当前任务授权，不能因完成产物检查而推断已获得上传许可。
