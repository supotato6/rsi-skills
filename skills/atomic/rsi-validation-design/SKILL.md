# 验证设计

输入是任务指标与方向、数据字典、可用时间、实体关系和部署情境。输出一份可执行的验证约定，供建模和独立评分复用。

1. 确认预测发生的时点、目标观察窗口、特征何时可获得，以及线上会遇到已见实体还是新实体。缺失的信息列为假设或待确认项。
2. 选择与部署匹配的划分。未来预测使用向前验证；新实体泛化使用分组隔离；存在两种需求时分别报告，避免未经判断就按行随机切分。历史实体在部署时合法出现的情境不必一律禁止跨时间重复。
3. 对窗口标签检查标签成熟时间，隔离跨越验证边界的目标观察窗口。没有数据可用日期时，不能宣称已证明无泄漏。
4. 划分之后，只在训练部分拟合填充、编码、标准化、特征选择和其他有学习过程的变换。目标编码采用训练内的交叉拟合；验证与测试仅应用冻结后的变换。
5. 核对任务指标、类别语义、正类、聚合方式、分组样本量和随机种子。沿用任务指定指标，不能为了分数更高擅自更换。

输出记录：划分规则或数据版本、训练与验证边界、指标约定、可用特征、泄漏检查结果和未解决问题。固定该约定后比较候选；如果确需修改划分，建立新的比较组，旧分数不能直接混排。

隐藏标签和最终测试不进入方案选择。验证设计本身不产出可信评分，实际评分使用 System 提供的独立评估入口。
