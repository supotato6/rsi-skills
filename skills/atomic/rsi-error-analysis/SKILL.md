# 错误分析

输入是绑定到确定候选的评估报告、公开日志及允许访问的验证诊断数据。输出带证据的故障分类和下一轮可检验假设。

先区分四类问题：执行失败、产物无效、验证约定或数据处理错误、有效候选的模型误差。前三类优先恢复有效性，不能把它们都归因为模型能力不足。

对执行失败定位具体阶段和首个有因果意义的错误。对产物问题检查列名、形状、ID 对齐、数值范围与缺失。对模型误差，使用已有且获准的验证结果，按时间、实体、类别或业务切片检查错误，保留每个切片的样本数。

区分已观察事实、推测原因和待验证结论。样本不足、诊断数据不可用或指标无差异时明确说明，不编造切片统计，也不读取隐藏测试来定位失败样本。

为下一轮提供：证据、假设、一个优先改动、验证方法、预期资源与停止条件。根据剩余预算决定修复、实验或收尾。缺少数据的假设可以保留为后续建议，不假称已证实。

修复应适用于同类输入；不能硬编码验证答案、删除困难样本或修改评分器。每次执行后的反馈继续绑定其真实候选，避免把旧版本分数附到新代码上。
