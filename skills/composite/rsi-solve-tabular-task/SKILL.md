# 完成表格预测任务

所需原子技能：`rsi-validation-design`、`rsi-tabular-modeling`、`rsi-artifact-check`、`rsi-error-analysis`、`rsi-experiment-review`。按当前步骤读取对应技能；不需要预先加载全部正文。

先确认任务输入、指标及方向、产物要求、可用工具与总预算。下面是默认路线，可根据已有证据跳过已完成步骤，记录理由。

| 当前条件 | 使用技能 | 传给下一步的结果 |
|---|---|---|
| 验证约定未建立或有泄漏疑问 | 验证设计 | 划分、特征可用边界、指标与未决事项 |
| 已有验证约定，需要有效基线或改动候选 | 表格建模 | 候选身份、配置、代码或模型、产物 |
| 候选已产生产物 | 产物检查 | 契约检查结果、阻断问题、候选绑定 |
| 本地检查通过且 System 允许评估 | System 的真实执行与独立评估入口 | 绑定候选的报告与剩余预算 |
| 执行、产物或模型效果需要诊断 | 错误分析 | 故障阶段、证据、改动假设 |
| 已有可比运行或需要决定是否继续 | 实验比较 | 当前有效最佳候选、下一步或停止理由 |

改进时，将诊断假设和实验比较决策交给建模步骤。先修复无效候选，再比较有效分数；验证约定变化后另立比较组。多个技能共同约束同一候选，依赖步骤顺序执行并共享原有预算。

预算耗尽、任务约定停止条件满足，或没有值得验证的改动时收尾。保留 System 选定的有效候选，检查最终交付与该候选一致；没有有效候选时交付失败原因与可恢复材料，不声称任务已评分成功。

隐藏测试不用于选方案；冻结候选后的最终测试由 System 控制。交付包含候选与产物路径、真实评估来源、实际加载技能、剩余限制，外部提交按任务授权执行。
