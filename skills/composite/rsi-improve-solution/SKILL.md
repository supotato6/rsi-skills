# 改进已有方案

所需原子技能：`rsi-artifact-check`、`rsi-error-analysis`、`rsi-experiment-review`、`rsi-tabular-modeling`、`rsi-validation-design`。诊断与比较可用于通用任务；表格建模仅在回归或分类任务适用。

输入是现有方案、候选历史、评估约定和剩余预算。先使用实验比较确认当前有效最佳候选和真正缺口，再按下表组织方法。

| 观察到的情况 | 原子技能组合 | 返回的决策依据 |
|---|---|---|
| 预算为零 | 实验比较；交付前使用产物检查 | 冻结已有有效候选，列出未评估版本 |
| 崩溃或产物无效 | 错误分析＋产物检查 | 根因、修复要求、是否值得消耗预算 |
| 怀疑验证泄漏或分数不可比 | 验证设计＋实验比较 | 修订约定或明确比较限制 |
| 有效表格候选效果不足 | 错误分析＋表格建模 | 一个带证据和代价的改动假设 |
| 其他任务需要领域方法 | 错误分析＋当前环境可用的领域能力 | 适用性与工具缺口，不强套表格模型 |

保留当前有效方案，在新的候选版本上执行改动。调用 System 评估之前用产物检查排除可本地发现的格式问题；随后将真实报告交给实验比较，决定保留、回退、继续或停止。

多个技能共用一个候选身份、任务状态、历史和预算。不能并行修改同一候选再把某一版评分归给另一版，也不能用自报训练分数替换独立评估。

当预算耗尽、目标满足或后续收益不足时交付 System 选定方案及证据。用户要求保留的未评估方案可另外交付并标明状态。没有获准评估入口或必要资料时说明限制，产物检查通过不等于已验证性能。
